# 极端群体状态：信号存在性检查

Owner 于 2026-09-27 明确：先看已有历史里模型输出最极端的时点，此后是否有可辨识的价格表现。
本轮不是新的概率模型、交易策略验收或实时阈值设计。每股最低3次是当前案例数量，不是长期限制。

## 本轮交付

- 入口：`tools/market_extreme_events.py`，无网络、语义推理、训练或参数搜索。
- 使用已有848个股票×日期状态、16只股票；行情为7/9～9/24的56个实际交易日。
- 三个已存在的指标分别分析：多空方向、操作方向、正负情绪平衡；不把它们加权成新分数。
- 每股每指标按状态值选最低3次，最高3次作参照。144个低值案例、144个高值案例，选点不读取未来收益。
- 观察入场日开盘至第10/20/30/60个交易日收盘的绝对收益，另外保留实际价格路径和相对入场价的最大跌幅。
- 每个事件保留完整多空/操作/情绪类别概率、抽样数量和三个模型判为该方向最强的帖子例子；这些例子不是人工真值。
- 全历史极端尚未到期时保持空值，不静默替换。另有明确区分的“当前可观察完整结果的历史区间”补充分析。
- 不同期限的主结果可能含不同案例，因此额外用原极端中的同一批已完成10/20/30日案例作比较；不重新选点，60日无结果不加入交集。

```bash

./.venv/bin/python tools/market_extreme_events.py \
  --source-run /Users/mac/Documents/trae_projects/MyResearcher/pipeline-runs/market-signal-state-contrast-20260927-final \

```

`--metrics` 可指定 `stance_index action_index emotion_balance` 的子集；`--count` 可增大。
`--output-dir` 指定一个空目录，不指定则新建时间戳目录。`--as-of latest` 使用输入行情表的最新日期，
不是联网获取最新市场。脚本读取 source-run 的 `daily-states.jsonl` 和其配置中的价格/原概率路径；
新增帖子状态需要先由既有聚合入口产生新的 source-run，不能以重新运行本脚本冒充更新了帖子。

输出：`REPORT.html`（逐股图、事件日期、分布和帖子）、`REPORT.md`（汇总）、
`report.json`（逐股数值）、`event-cases.jsonl`（所有案例和实际路径）、`run-config.json`。

## 实际结果与允许结论

全历史最看空的48个时点中，10/20/30日分别有38/25/22个已完整观察。
股票等权的平均绝对收益为 +3.9235%/+5.6433%/+5.3873%，同股普通日对应
+0.2505%/+0.9375%/+1.0144%。20日有10/16只股票的低值案例均值高于普通日；
各股低值均值的中位数 +2.6386%，每次剔除一只股票后，低值相对普通日的平均差值仍为
+2.7367～+5.7280个百分点。因此不能将当前数据描述成“连极端状态也完全没有关系”。

同一批已有10/20/30日结果的22个原始看空极端时点、14只股票，等权收益依次为
+5.7352%/+7.7843%/+5.3873%；同一区间普通日为 +3.0601%/+4.0864%/+1.0144%。
这是一条反向关联的探索性线索，不是因果、显著性或可交易证据。

负面情绪极端不呈同样一致的形态：全历史主结果10/20/30日相对普通日差值为
-1.3168/+1.0896/-0.2212个百分点；同案例对照也没有稳定的正增量。不能用一个情绪平衡分数替代各种具体群体心态。

例：鼎龙7/17看空极端之后，10/20/30日收益 -10.0851%/+2.7991%/+2.9089%，期间最多跌至入场价下方14.0779%；
7/30对应 +11.4655%/+3.7213%/-2.7011%；9/1之后10日 -8.2511%，更长期限尚未到期。
这既保留可能的延迟，也显示同样“很看空”并不保证反弹或低风险。

## 必须保留的解释边界

- 全历史最低值是回顾性选点，不要求在当时可实时识别；本轮明确不将其包装成策略。
- 先逐股计算，再股票等权；普通日排除该指标选中的低/高值日。
- 普通日尚未匹配此前涨跌、成交量或行情阶段；差值可能反映行情反转，而不是独立语义贡献。
- 每股每日最多16条抽样概率，不等于整个股吧；历史模型冻结晚于部分行情，不是全系统前瞻结果。
- 3个日期可能接近，持有区间可能重叠，股票受共同市场影响；案例数不等于独立机会数。
- 60日全部未到期；没有扣交易费用、滑点，也没有合成为账户业绩。
- 不据此修改M12、标注、类别、权重或买卖规则；不宣称整个项目成功或失败。
