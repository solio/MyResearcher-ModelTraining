## 规则(纯字符串匹配,成本≈0)

- **宣言层**(规则直接计数,不送模型):割肉|清仓|满仓|全仓|空仓|销户|梭哈|打满|我割了|我卖了|已卖|已割|不玩了|跑路|离场
- **强烈层**(送推理 LLM 精读):叹号;骂词大家族(垃圾/拉几辣几垃鸡辣鸡/废物/机狗大狗真狗t狗/苟/猪力/逆子/坑爹/砸中/九菜韭菜/杂毛/渣渣/恶庄/耍流氓/害人/飞舞/有病/妈的/操你妈/滚);极端词(必涨必跌/起飞/崩盘/血雨腥风/欲哭无泪/完蛋去求);逃跑词(快跑/快逃/逃命/大逃亡/熊来了/大跌开始);亏死气死吓死烦死闷死

## 架构落位

```
全部帖子(死规则,成本≈0)
  ├─ 宣言层 ~2.8% → 规则计数(卖出/买入压力)
  ├─ 强烈层 ~12%  → 推理 LLM 精读(87万条规模 ≈ 10万条,成本可算)
  └─ 中间层 ~85%  → 量/沉默统计(“没有帖子!”的价值在此)
```

成本:87 万条时仅 ~10 万条吃贵模型;随模式卡增长(逆向买入宣言等)还可再降。
**边界**:① 逆向买入宣言形式平静,全落中间层,本规则不覆盖,走模式卡;② 规则只按标题(90%+帖子只有标题),正文未计;③ 强烈层真值 n=13,定阈值前需扩样仲裁 ~30 条。
