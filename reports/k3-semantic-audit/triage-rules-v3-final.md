# 表达强度三档判据定稿(规则 v3.1)与链路架构

2026-10-09|判据来源:Owner 50/50 复核(v2)|规则 vs Owner 一致 76%

## Owner 三档分流与判据反推

Owner 把 50 条分为:**激动 34 / 强调 12 / 平静 4**。
判据(反推):激动=骂/恐慌/急呼/行动激动(加仓宣言、憋大招盼涨);强调=叹号+判断/预测/喊单/利好/反讽("真是高手!!");平静=数据分析/长句论证(即使有叹号或看空内容)。
方向未改(#19"融券苟进货"仍判空、#46"廉价筹码"仍判多)——**"空"是作者的判断,"买"是作者的动作,两者分开各自成立**。这实证:不需要"看跌买入"独立档位,需要"判断(方向)+ 动作"两个字段的组合(h1-1007 原设计即如此;过渡档是组合显示标签,不是新档位)。

## 分层对率(Owner 为真值)

| 层 | n | K3 | 学生 |
|---|---|---|---|
| 激动 | 34 | **85%** | 71% |
| 强调 | 12 | **83%** | **42%** |

学生在强调层最弱(叹号+判断里反讽/黑话多),激动层它也能混(情绪外露好判)。K3 两层都稳。

## 规则 v3.1(最终版)

- **宣言**(计数用):割肉/清仓/满仓/空仓/销户/梭哈/已卖/已割…
- **激动**(送推理 LLM 精读):**叹号连用(!!/！!)**;骂词(垃圾/拉几拉机辣几/烂股烂票/飞舞/真狗/苟/猪力/逆子/坑爹/韭菜九菜/杂毛/恶庄/耍流氓/妈的/天理…);恐慌(完蛋/欲哭无泪/快跑/逃命/血雨腥风/熊来了/崩/破防/绷不住…);情感强度(坚决看好/绝不/不放松/一定要/磨死/套人/接盘)
- **强调**(便宜模型粗读或规则计数):单叹号;必涨/必跌/恒盘/立帖为证
- **平静**(量/沉默统计):其余

## 验证

- **vs Owner(50 条):一致 76%**(38/50)。
- **激动漏判率 18%**(Owner 判激动而规则未捕:6/34——"要跌多少才满意"哀鸣、"加到6层"宣言、"是人是鬼"骂)。
- 残留分歧均为语境/反讽/期待类("我韭菜花"自嘲、"大聪明韭菜接盘"反讽、"事出反常必有妖…基本有数了"冷静分析含"害人")——**规则天花板,归 LLM 精读,不再补**。
- **全库 376,887 条:宣言 2.75% / 激动 6.16% / 强调 6.43% / 平静 84.66%**。

## 链路架构(定稿)

```
全部帖子(死规则,成本≈0)
  ├─ 宣言 2.8% → 规则计数:卖出/买入压力
  ├─ 激动 6.2% → 推理 LLM 精读(方向+动作+理由;K3 85% 实测)
  ├─ 强调 6.4% → 便宜模型粗读或规则计数(学生 42%,不可靠,建议粗读)
  └─ 平静 84.7% → 量与沉默统计("没有帖子!"的价值层)
```

成本:87 万条时,精读量 ≈ 5.4 万条(激动 6.2%),粗读量 ≈ 5.6 万条(强调 6.4%);比最初"强烈层 12% 全精读"的方案再省一半。

## 遗留(诚实)

- 激动漏判 18%:可接受(漏进强调层,仍会被粗读看到,只是精度低);若业务要求零漏判,补"加到.*层|继续加|够了吧|是人是鬼"等规则,一致率可再升 ~5pp,但规则维护成本上升。
- 强调层的处理方式未定(便宜模型粗读 vs 规则计数)——学生在此层仅 42%,建议用 ds-flash 级粗读+一致率分诊。
- "判断×动作"组合显示标签(看跌买入/看涨卖出)的产出依赖精读阶段的"动作"字段,本轮未实测。
