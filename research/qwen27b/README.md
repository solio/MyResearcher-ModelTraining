## 恢复和验证

先在仓库根目录执行只读核验：

```bash
python3 research/qwen27b/verify_source.py
```

需要恢复源码时，先把 `source/` 和外部完整工作包分别解到新工作目录，比较差异，
再采用需要的版本。现有文件不应被历史快照直接覆盖。两者都保留 MyResearcher
相对目录结构，便于恢复原有布局。

历史脚本有绝对路径、已到期截止时间、旧 SSH 端口和 PID。它们是实际执行过的版本，
不是新机器的一键启动入口。后续部署应按使用交接重新指定连接、预算、权重路径和
实际硬件；不要直接执行历史 `chain_session.py` 或复制旧 deadline。

原有测试使用本地模拟服务，不消耗 GPU。部分测试需要外部批次输入，因此应先恢复
对应输入，再在独立副本内运行，避免测试写入冻结结果目录。源码归档不修改原输入、
提示词和模型回答；研究结论、标签和分数不会因为提交而自动获得质量认证。
